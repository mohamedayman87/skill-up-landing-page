# SkillUp

A landing page for a made-up online learning platform. It's built with plain HTML, CSS and vanilla JavaScript on top of Bootstrap 5. There's no framework and no build step. Open `index.html` and it runs.

## What's in it

- **Hero** with floating stat cards and a video-style preview
- **Why SkillUp** section with hover-animated feature cards
- **Course grid** you can filter by Business, Languages or Marketing
- **Favorites**: heart any course to save it
- **Enroll modal** that fills in the course name and price you clicked, then confirms with a toast
- **Testimonials**
- **Contact form** with validation, a fake "sending" state and a success toast
- **Navbar** with a frosted-glass look, scroll-spy highlighting and smooth scrolling, and it closes itself on mobile after you tap a link

## Built with

Bootstrap 5.3, Font Awesome 6, Google Fonts (Plus Jakarta Sans, Readex Pro) and vanilla JS. The colors, radii and transitions live in CSS variables in `style.css`, so re-theming means changing a handful of values.

## Run it

Clone the repo and open `index.html` in a browser.

## Files

- `index.html`: markup and content
- `style.css`: theme variables and custom styles
- `script.js`: filtering, modal, form handling, scroll behavior
